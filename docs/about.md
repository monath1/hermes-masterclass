# About this edition

Hermes Agent Masterclass is a practical textbook for operating Hermes Agent on macOS from an Apple-silicon Mac mini. The intended reader is beginner-to-intermediate: someone who understands that agents exist, but wants an operational mental model and a safe, repeatable deployment.

## Product baseline

This edition is pinned to **Hermes Agent v0.20.5 (2026-08-19)**, tag `v2026.8.19`. Product behavior, commands, settings, and interface labels are version-sensitive facts. Authors must verify them against the pinned checkout and cite the relevant official source; `research/hermes-v2026.8.19-source-map.md` provides the starting paths.

## Editorial and source policy

All prose, examples, diagrams, exercises, and configuration artifacts are original. Explanations are paraphrased from primary sources, not copied from other books. The preferred evidence order is pinned Hermes material, official OpenAI documentation, official Apple and provider material, Canadian government sources where jurisdiction matters, and primary standards or research where needed.

This is a Hermes textbook. Codex appears only as a specialist work harness that Hermes may delegate to under a bounded contract; it is not the always-on supervisor. The curated extension stack is Hermes-native skills, Hermes plugins, and Hermes-compatible MCP servers—not Codex marketplace plugins.
